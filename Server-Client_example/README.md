#Project Δίκτυα επικοινωνιών 2026

## Περιγραφή
Στο παραπάνω project γίνεται η υλοποίηση ενός συστήματος ανταλλαγής μηνυμάτων μεταξύ ενός server και πολλαπλών client μέσω java sockets. Συγκεκριμένα οι δυο οντότητες επικοινωνούν μεταξύ τους με requests από τους client και reply από το server, τερματίζοντας την σύνδεση μετά από κάθε συναλλαγή. Μέσω αυτών των μηνυμάτων υποστηρίζονται οι λειτουργείες δημιουργίας λογαριασμού client, αποστολής μηνυμάτων μεταξύ client και η συγκέντρωση εισερχομένων μηνυμάτων σε ένα ενιαιο messagebox

---

### Υποθέσεις που έγιναν
-Κάθε client κανει ένα request και μετά διακόπτεται η σύνδεση του με το Server
-Τα αναγνωριστικά κλειδιά μηνυμάτων και authtoken τέθηκαν στις τυχαίες τιμές 1 και 1024


---

## Τεχνολογίες που χρησιμοποιήθηκαν στην υλοποίηση
- TCP Scokets
- I/O Streams
- Multithreading (Μέσω Κληρονομικότητας)

## Κλασεις του source code

### Message
Μήνυμα μεταξύ 2 χρηστών
Πεδία:
- ID:Αναγνωριστικό κλειδί
- sender:usrname αποστολέα μηνύματος
- receiver:username παραλήπτη μηνύματος
- body: κείμενο
- isRead: σημαία για αν το μήνυμα έχει διαβαστεί από τον παραλήπτη

---

### Account
Λογαριασμός στο σύστημα που αντιστοιχεί σε κάθε χρήστη
Πεδία:
- username:Ψευδώνυμο που αντιστοιχεί σε κάθε λογαριασμό
- authToken:Token που χρησιμοποιείται για την αποτροπή διαχείρισης και χρήσης Account από χρήστες που δεν τους ανοικουν
- mesagebBox:Συλλογη με όλα τα εισερχόμενα μηνύματα ενός χρήστη

---

### MesssagingServer
Το server του συστήματος
- Συνδέεται με τους client μέσω serversocket
- Αναθέτει κάθε αίτημα με ένα thread ClientHandler
- Αποθηκεύει τις δομές δεόμενων του συστήματος

---

### ClientHandler
- Αναγνωρίζει και εκτελεί και τις 6 διαφορετικές λειτουργίες του συστήματος(Client requests)\
- Επιστέφει το αποτέλεσμα πίσω στον χρήστη

---

### MessagignClient
-Συνδέεται με τον server
-Στέλνει τα ανάλογα αιτήματα
-Εμφανίζει τα αποτελέσματα
